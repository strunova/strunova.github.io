# STRUNOVA website

Source of the official STRUNOVA website: https://strunova.github.io

STRUNOVA, The Guitar Harmony Engine, is a desktop application for finding, exploring and identifying guitar chords. The application's code lives in [Themasterofbuttons/strunova](https://github.com/Themasterofbuttons/strunova).

The site is plain HTML and CSS, published by GitHub Pages from the `main` branch.
